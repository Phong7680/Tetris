# Tetris Battle

> **開発時期**: 2022年7月

## 概要
**Tetris Battle**は、クラシックなテトリスとバトルシステムを組み合わせたゲームです。プレイヤーはテトリミノブロックを配置してラインを消去し、コンボやパーフェクトクリアで敵を攻撃します。

## 主な特徴

### テトリスゲームプレイ
- 標準的な7種類のテトリミノ（I、O、T、S、Z、L、J）
- 10×20のプレイフィールド
- **ホールド**機能（ブロックを保持）
- **ネクストブロック**表示（次のブロック）
- **ハードドロップ**と**ソフトドロップ**
- 時計回り・反時計回りの回転

### バトルシステム
- **敵のHP**：ライン消去で減少
- **連鎖（Ren）**：連続してラインを消すと攻撃力アップ
- **パーフェクトクリア**：フィールドを完全にクリアすると特別ボーナス
- **弾（Bullet）**：攻撃の視覚エフェクト
- **ヘルプシステム**：
  - `A`：ブロック交換（3回まで）
  - `S`：速度を遅くする
  - `D`：攻撃力2倍

### その他の機能
- ニューゲーム、コンティニュー、記録を含むメニューシステム
- ゲーム進行状況の保存・読み込み
- トップ10ランキング
- ポーズモード
- 勝利・ゲームオーバーエフェクト

## 操作方法

| キー | 機能 |
|------|------|
| ← → | ブロックを左右に移動 |
| ↑ | ハードドロップ（高速落下） |
| ↓ | ソフトドロップ（速く落下） |
| Z | 反時計回りに回転 |
| X | 時計回りに回転 |
| C | ホールド（ブロックを保持） |
| A | ヘルプ：現在のブロックを交換（3回） |
| S | ヘルプ：速度を遅くする |
| D | ヘルプ：攻撃力2倍 |
| P | ポーズ/再開 |
| Q | ゲーム終了 |

## グラフィックライブラリ

本ゲームは**三重大学**が開発した2Dグラフィックライブラリ**EzGraph**を使用しています。EzGraphはグラフィック処理、キーボードイベント、ゲームループのためのシンプルなAPIを提供します。

### 使用しているEzGraphの機能：
- `EzSetKeyHandler()`：キーボードイベント処理
- `EzSetTimerHandler()`：カスタマイズ可能なFPSでのゲームループ
- `EzReadXPM()`：XPM画像の読み込みと表示
- `EzDrawStringB()`, `EzFillBoxB()`：テキストと図形の描画
- `EzShowBuffer()`：ダブルバッファリングでちらつき防止
- `EzEventLoop()`：メインイベントループ

## プロジェクト構成

```
CONTEST/
├── main.c          # エントリーポイント、メニュー初期化
├── game.c          # メインゲームロジック（ブロック、衝突判定、スコア）
├── graphic.c       # グラフィック描画（メニュー、フィールド、エフェクト）
├── keyboard.c      # 入力処理と制御
├── library.h       # 構造体、定数、関数プロトタイプの定義
├── *.xpm           # スプライト画像ファイル（戦車、敵、ブロック）
├── result.txt      # ランキング保存
├── stage.txt       # プレイフィールド状態保存
└── var.txt         # ゲーム変数保存
```

## コンパイルと実行

### 必要要件
- Cコンパイラ（gcc）
- EzGraphライブラリのインストール
- X11/Windowsをサポートするオペレーティングシステム

### コンパイルコマンド
```bash
gcc -o game main.c game.c graphic.c keyboard.c -lEzGraph -lX11 -lm
```

### ゲーム実行
```bash
./game
```

## スコアシステム

- **Attack**：与えた総ダメージ
- **Enemy HP**：敵の残りHP（初期値100）
- **連鎖（Ren）**：途切れずに消した連続ライン数
- **Perfect Clear**：フィールドを完全にクリア

### 勝利・敗北条件
- **勝利**：敵のHPが0になったとき
- **ゲームオーバー**：新しいブロックが出現できないとき（フィールドが満杯）
